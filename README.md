# TechCare: รอยต่อสัญญาณ

ต้นแบบ React + TypeScript + React Three Fiber สำหรับแผนที่เมือง 3D และ Phaser 3 สำหรับฉากสืบสวน 2D ของแผนเกม 3 ตอน

## เปิดเกม

```sh
npm install
npm run dev
```

เปิด http://127.0.0.1:5180/ · build ด้วย `npm run build` · ตรวจด้วย `npm test` และ `npx playwright test`

ใช้ Node 24.x และเตรียมไฟล์ภาพภายนอกตาม [ASSETS_SETUP.md](ASSETS_SETUP.md) ก่อน build: repository Public นี้ไม่แจกภาพจากแพ็กภายนอกซ้ำ ตรวจไฟล์ด้วย `npm run assets:check` ส่วนวิธีเผยแพร่เกมพร้อม Asset จากเครื่องผู้พัฒนาอยู่ใน [DEPLOYMENT.md](DEPLOYMENT.md) การ push Git เพียงอย่างเดียวไม่สั่ง deploy

## หน้าเข้าเกมและบทเปิด

คดีใหม่: BLACKBOX ของอาราซาก้าถูกขโมย คินรับงานตามคืนและพบเบาะแสของคู่หูที่หายไป บทเปิดไม่ยืนยันตัวตนคนร้าย กล้องเป็นหลักฐานจุดแรกของคดีระดับเครือข่ายฉุกเฉิน

- Play → บทเปิดสืบคดี5ช็อต → แผนที่เมือง 3D กดถัดไป ย้อนกลับ หรือข้ามได้
- แฟ้มเจ้าหน้าที่ตั้งชื่อในเครื่อง Settings แยกเสียงเพลง/เอฟเฟกต์ ลดการเคลื่อนไหว และเต็มจอ
- Escape เปิดเมนูภารกิจ ออกจากภารกิจแล้วกลับเข้าเล่นต่อได้ในแท็บเดิม
- จำเควสต์ พื้นที่ปัจจุบัน และพื้นที่ที่ปลดล็อกในเครื่อง ตำแหน่งเดิน/โค้ดที่ยังไม่ส่งไม่ถูกเซฟ เริ่มคดีใหม่ได้จากเมนูภารกิจโดยไม่ลบชื่อหรือการตั้งค่า
- ฉากตัวอย่างทั้ง4ย้ายไปที่ เมนู → ฉากและข้อมูลต้นแบบ
- รายละเอียดไฟล์ภาพ แอนิเมชัน และเสียงอยู่ใน ENTRY_FLOW.md

## สิ่งที่ทดลองได้

- แผนที่เมือง 3D: ลากหมุน360° ล้อเมาส์ซูม คลิกขวาลากเลื่อน เลือกหมุดแล้วกดเข้าสำรวจ มีปุ่มควบคุมและรายชื่อพื้นที่รองรับคีย์บอร์ด
- ร้านช่าง: WASD/ลูกศรเดิน 4 ทิศ กด E ใกล้พยานหรือเครื่องกล้อง มีการชนอาคาร
- ภายในกล้อง: ตัวละครจิ๋ว เดินตามทางวงจรผ่านตำแหน่งจุดกู้ระบบ 7 จุด
- ห้องบอส: คินกลับเป็นร่างปกติ ดูตำแหน่งเกราะและหน้าต่างตัวอย่างโจทย์
- โจทย์สาธิต src/alt: พิมพ์โค้ด ดูพรีวิว ใช้คำใบ้และเฉลยสีชมพู ตรวจคำตอบ และทดลองเสียโล่
- สมุดคดี J, ปิดหน้าต่างด้วย Escape, เพลงเปิดปิดได้

## ขอบเขตของระยะนี้

นี่คือฉากตัวอย่างพร้อมแผนที่และความคืบหน้าขั้นต้น ยังไม่มีเนื้อหา21โจทย์ บอส3ช่วงจริง เซฟภารกิจเต็ม แบบวัด หรือการจบคดี จุดทั้งเจ็ดเปิดโจทย์ตัวอย่างเดียวกันโดยระบุชัดในหน้าต่าง แก้ตัวอย่าง CAM-07 สำเร็จเปิดข่าวกรองสถานีสื่อสาร บันทึกข่าวกรองแล้วเปิดศูนย์ควบคุม โดยทั้งสองจุดยังไม่ใช่ตอนเรียนเต็ม

ขั้นถัดไปหลังผู้ใช้ตรวจภาพ: บทนำ HTML → ตอนแรก 7 โจทย์จริงและบอส → เซฟและทดลองเล่น → ขยายตอน 2–3 และเผยแพร่แยกจากเกมเก่า

## แหล่งภาพและเสียง

ใช้สไปรต์ชาย/พยานและ props จาก Cyberpunk City Ext และอาคารจาก Neo Zero ที่ผู้ใช้ให้ แยกต้นฉบับไว้ art-source และแยกไฟล์ภาพภายนอกออกจาก Git Public ตามรายการ checksum ใน external-assets.json ตัวเกมออนไลน์จัดส่งจากเครื่องผู้พัฒนาที่มีไฟล์เหล่านี้ ไม่แจกแพ็กต้นฉบับ

Neon District ยังไม่ถูกใช้: ขนาดภาพไม่ตรง README และมีข้อห้ามแจก asset ดิบซ้ำ เพลงต้นฉบับสังเคราะห์ของเกม TechCare เดิมถูกนำมาใช้ซ้ำ ภาพ NULL จากเกมเดิมเป็นภาพอ้างอิงบอสชั่วคราว

เนื้อหาอนาคตอ้างอิง IS216_Part4_for_Screen.pdf ที่ผู้ใช้แนบ ตัวอย่างจะตรวจและปรับเป็น HTML ปัจจุบันก่อนใช้สอน

## โครงสร้าง

narrative/case.ts เป็นข้อมูลคดี/บทเปิด/พยาน/สมุดคดีร่วมกัน, city/ เป็นเมือง3D/กฎปลดล็อก/ข่าวกรอง, model.ts เป็นสถานะ/การเดิน/การโต้ตอบ2D, World.ts เป็น Phaser renderer ผ่าน MissionCanvas.tsx, App.tsx เลือกหน้าเข้าเกม/แกลเลอรี, GameApp.tsx เลือก renderer ที่ใช้งานและ DOM UI, entry/ เป็นเมนูและstoryboard, assets.ts เป็น manifest และ style.css เป็น runtime design tokens

ภาพตรวจอยู่ใน evidence/ และ tools/capture.mjs ใช้สร้างภาพทั้ง 4 ฉากใหม่

## คินพาฝึกเล่น

คดีใหม่เริ่มช่วงแนะนำตัวและฝึกใช้แมพด้วยคินคนเดิม มี5สีหน้า ปากขยับ เสียงตืด และตัวเลือกตอบกลับ จากนั้นพาเดินคุยอรุณและแก้โจทย์สาธิตแรกผ่านปุ่มจริง ข้ามได้ตลอดและดูซ้ำจากเมนูได้ เซฟเดิมเริ่มฝึกแบบสมัครใจ ไม่ล้างหลักฐาน
