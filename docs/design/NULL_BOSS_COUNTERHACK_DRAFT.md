# NULL — Counterhack: คินถูกยึดสัญญาณ

วันที่ 2 พฤศจิกายน 2569 · ร่างสำหรับคุย ยังไม่เริ่มพัฒนา

## คำสั่งล่าสุดของผู้ใช้

ยกเลิกการคุยบอสแบบเดินหลบ/พุ่งหลบและโล่–สะพานทั้งหมด ต้องการให้คินถูก NULL แฮ็ก ทำให้แก้โค้ดยากขึ้น แล้วผู้เล่นจู่โจมกลับผ่านมินิเกมสนุกที่ไม่ยาว เก็บ Prompt ตอนจบก่อนหน้าไว้ด้วย ผู้ใช้เลือกแล้ว: **ต่อวงจรส่งสัญญาณสวนกลับ** โดยหมุนทางแล้วกดส่ง เห็นไฟวิ่งและคินโจมตีตามผลที่ทำ

## แนวเสนอ — กู้ช่องสัญญาณแล้วส่งแพ็กเก็ตสวนกลับ

ผู้เล่นยังเป็นเจ้าหน้าที่สนับสนุน คินอยู่ในห้อง BLACKBOX NULL ยึดอุปกรณ์สื่อสารของคินจนคำสั่งของผู้เล่นส่งเข้าไปไม่ได้ ผู้เล่นกู้หน้าเทอร์มินัลจำลองด้วย HTML/CSS ที่เรียนแล้ว จากนั้นใช้ช่องที่กู้ได้ส่งสัญญาณสวนกลับ

วงจร: NULL แทรกโค้ด → ผู้เล่นหาส่วนผิดและซ่อม → ปลดล็อกมินิเกมสวนกลับ → ผู้เล่นส่งสัญญาณสำเร็จ → คินโจมตี/ระบบ NULL เสียหนึ่งชั้น → บอสเปลี่ยนท่าและสภาพฉาก

การแทรกโค้ดเป็นโจทย์เริ่มต้นที่ผู้เล่นมองเห็น ตรวจต้นฉบับกับสำเนาได้ ไม่เปลี่ยนร่างที่ผู้เล่นกำลังแก้อยู่แบบสุ่ม ไม่สลับปุ่มพิมพ์หรือทำข้อความอ่านไม่ได้ ความยากมาจากเนื้อหา ไม่จับเวลาอ่าน/เขียน เอฟเฟกต์แฮ็กใช้ขอบจอ เสียงขัดจังหวะสั้น และภาพคินที่การเชื่อมต่อสะดุด โดยเคารพ mute/reduced motion

ตัวอย่างงานซ่อม: href ชี้สำเนาแทนต้นฉบับ; selector เลือก id ทั้งที่เป้าหมายเป็น class; ส่วนรายงานถูกจัดผิดที่ ให้ใช้เฉพาะสิ่งที่สอนในตอนสามแล้ว ไม่สร้างความเข้าใจว่า HTML/CSS เป็นเครื่องมือโจมตีเครือข่ายจริง

## มินิเกมหลักที่แนะนำ — ต่อทางส่งสัญญาณ

แผงวงจรเล็กประมาณ 3×4 ช่อง มีต้นทางของคินกับปลายทาง NULL ผู้เล่นคลิกหมุนข้อต่อไม่กี่ชิ้น แล้วกดส่งเพื่อให้เห็นแพ็กเก็ตวิ่งจริง ทางที่ต่อสำเร็จเปิดให้คินสวนกลับได้ มีตรวจทางก่อนส่งและใช้คีย์บอร์ดเลือก/หมุนช่องได้ จำนวนช่องและเวลาต่อรอบเป็นค่าเสนอรอทดลอง ไม่ใช่เกณฑ์จับเวลาแพ้

- รอบแรก: ทางเรียบง่าย สอนหมุนแล้วส่ง แพ็กเก็ตพุ่งกลับตามสายที่ NULL ใช้แฮ็กคิน
- รอบสอง: มีตัวดักสัญญาณหนึ่งจุดให้เดินทางอ้อม เปิดข้อมูลว่าแต่ละชิ้นทำอะไรไว้ชัด
- รอบสุดท้าย: มีจุดขยายสัญญาณให้ต่อผ่านก่อนถึงแกน ทำให้คินปลดอุปกรณ์ BLACKBOX ได้หลังโจมตีสำเร็จ

ใช้กลไกเดิมที่เพิ่มเงื่อนไขทีละอย่าง เป้าหมายร่างสามรอบ ช่วงมินิเกมรวมประมาณ 1–2 นาที ส่วนไฟต์รวมราว 3–5 นาทีขึ้นกับเวลาคิดโค้ด ไม่รอให้ครบเวลาและไม่กำหนดเวลาอ่าน/พิมพ์ ทั้งจำนวนรอบและระยะเวลายังไม่ได้รับเลือก

## ทางเลือกที่ได้คุย — เลือกข้อ 1 แล้ว

1. ต่อวงจรส่งสัญญาณ: หมุนข้อต่อ เลือกเส้นทางแล้วส่ง มีพื้นที่ให้คิดและชนะจากการวางแผน (แนะนำ)
2. สะท้อนแพ็กเก็ต: คุมแผงรับสัญญาณสามช่อง ดักลูกโจมตีแล้วส่งคืน เน้นปฏิกิริยา ช่วงละสั้น มีโหมดช่วยหากเลือกแนวนี้
3. จับจังหวะเจาะเกราะ: กดเมื่อจุดสแกนเข้าแถบเป้าหมายเพื่อยิงสวน แสดง feedback และเสียงชัด เน้นจังหวะมากกว่าความรู้

ยังไม่เลือกระบบแพ้/ความเสียหาย/จำนวนรอบ/โจทย์จริง/รูปลักษณ์บอสท้ายเรื่อง ไม่ยกข้อตกลงจากไฟต์ที่ยกเลิกกลับมาโดยอัตโนมัติ Prompt ตอนที่สามเดิมเก็บครบใน CONTROL03_PROMPT_DRAFT.md การออกแบบนี้แก้เฉพาะข้อเสนอบอส

## Prompt บอสฉบับปรับแนวทาง

ข้อเสนอสามรอบด้านล่างเป็นรายละเอียดร่างเพื่อให้ผู้ใช้พิจารณา ไม่ใช่คำสั่งเริ่มเขียนเกม

```text
ออกแบบบอส NULL ในเกม TechCare: รอยต่อสัญญาณ โดยใช้รูปแบบ
คินถูกแฮ็ก → กู้โค้ด → ต่อวงจรส่งสัญญาณสวนกลับ → คินโจมตี

ผู้เล่นเป็นเจ้าหน้าที่สนับสนุนผ่านเทอร์มินัล NULL ยึดช่องสื่อสาร
ของคินและแทรกส่วนผิดในหน้า HTML/CSS จำลอง ผู้เล่นแก้ส่วนผิด
ด้วยทักษะที่เรียนแล้ว จากนั้นปลดล็อกแผงส่งสัญญาณสวนกลับ
ให้สิ่งที่ผู้เล่นลงมือทำเป็นต้นเหตุของการโจมตีและการเปลี่ยนฉาก

ใช้มินิเกมหลักเป็นวงจรขนาดเล็ก คลิกหมุนข้อต่อหรือใช้คีย์บอร์ด
ให้เชื่อมต้นทางคินถึงปลายทาง NULL แล้วกดส่ง
แพ็กเก็ตวิ่งตามเส้นทางจริง ตรวจจุดที่ขาดได้
ส่งผิดให้แก้เฉพาะวงจร ไม่ต้องทำโจทย์ HTML/CSS ที่ผ่านแล้วซ้ำ

เสนอสามรอบสั้นที่ใช้กลไกเดียวกันและเพิ่มเงื่อนไขทีละอย่าง:
1. กู้ช่องสื่อสาร: ซ่อม HTML ที่ชี้แฟ้มผิด ต่อทางตรงกลับไปหา NULL
   สำเร็จแล้วคินหลุดจากการล็อกและโจมตีเกราะชั้นแรก
2. ฝ่าตัวดัก: ซ่อม CSS selector ที่ NULL เปลี่ยน ต่อทางอ้อมตัวดัก
   สำเร็จแล้วชุดจอของ NULL ดับเป็นแนว เกราะแตกและคินสวนกลับ
3. ตัดแกน BLACKBOX: ซ่อมหน้าควบคุมสั้นจากโครงที่ให้
   ต่อผ่านตัวขยายสัญญาณก่อนเข้าปลายทาง ส่งคลื่นสุดท้าย
   คินเข้าถึงแท่นและถอด BLACKBOX เก็บหลักฐานต้นฉบับได้

เป้าหมายร่างคือไฟต์กระชับประมาณ 3–5 นาทีตามเวลาคิดของผู้เล่น
ไม่ใช้เวลานี้เป็นตัวจับเวลาแพ้ ไม่ยืดการโจมตีเพื่อให้ครบความยาว
ไม่จับเวลาอ่านหรือเขียนโค้ด

ทำความยากผ่านโจทย์ที่ถูกแทรกก่อนเริ่มรอบ มีคำใบ้และเฉลย
อย่าสุ่มเปลี่ยนร่างโค้ดที่ผู้เล่นกำลังเขียน สลับปุ่มพิมพ์
หรือใส่ glitch ทับข้อความจนอ่านไม่ได้

ให้ความรู้สึกถูกแฮ็กด้วยภาพสัญญาณของคินสะดุด สายสัญญาณม่วง
จาก NULL ไฟเตือน และเสียงแทรกสั้น ตอนสวนกลับสายเปลี่ยนเป็นฟ้า
มีแพ็กเก็ตวิ่ง คินมีท่าโจมตีจริง NULL มีท่ารับแรงกระแทก
แสง/อุปกรณ์ในห้องเปลี่ยนหลังแต่ละรอบ ปุ่มมี hover/focus/pressed
เคารพ mute และ reduced motion ไม่มีเสียงพากย์เพิ่ม

ใช้หน้าพิมพ์ HTML/CSS เดิม คำใบ้และปุ่มเฉลยสีชมพู
พรีวิวปลอดภัย และการตรวจคำตอบที่ยอมรับรูปแบบเทียบเท่า
แยกคะแนนเกมจากการใช้ตัวช่วย

คงตัวตนจริงของ NULL และความสัมพันธ์กับคู่หูเป็นประเด็นบท
ที่ยังไม่ตกลง ไม่ดึงร่างยักษ์หรือระบบเดินหลบจากแบบที่ยกเลิกมาเอง
ทำภาพ/flow ให้ตรวจทิศทางก่อนพัฒนา ไม่ commit/push/deploy
```
