# NULL — ออกแบบ epic fight

> **ยกเลิกแนวทางนี้แล้วตามคำขอผู้ใช้วันที่ 2 พฤศจิกายน 2569**: การเดินหลบ/พุ่งหลบ ทางโล่–สะพาน ระยะเวลา 6–8 นาที และข้อตกลงบอสจากการคุยชุดนี้ไม่ใช้เป็นข้อกำหนดพัฒนาต่อ เก็บไว้เป็นประวัติเท่านั้น แนวใหม่คือคินถูก NULL แฮ็ก แก้โค้ดที่ถูกแทรก และโจมตีสวนด้วยมินิเกมสั้น ดู NULL_BOSS_COUNTERHACK_DRAFT.md รายละเอียดใหม่ยังอยู่ระหว่างคุย

วันที่ 2 พฤศจิกายน 2569 · **ข้อเสนอสำหรับสนทนา ยังไม่อนุมัติพัฒนา**

## คำขอและข้อกำหนดเดิม

ผู้ใช้ต้องการบอสที่สนุกและมีจังหวะสู้จริง มากกว่าตอบโจทย์แล้วเล่นคลิปโจมตี เก็บ Prompt ตอนที่ 3 ฉบับก่อนหน้าไว้ที่ CONTROL03_PROMPT_DRAFT.md โดยยังไม่แก้เกม

คงคดี BLACKBOX การเป็นเจ้าหน้าที่สนับสนุนของผู้เล่น คินลงพื้นที่ และทักษะ HTML/CSS จากเจ็ดด่านก่อนบอส ไม่สร้างภารกิจที่ต้องรู้ทักษะใหม่ทันที ไม่จับเวลาอ่านหรือพิมพ์ คงตัวช่วยและแยกคะแนนเกมจากผลการเรียน

## แนวทางเสนอ: สนามที่เปลี่ยนตามคำสั่งของผู้เล่น

สลับช่วงรับมือการโจมตีที่สั้นกับช่วง hack ปลอดภัย เมื่อเปิด editor หยุดอันตรายเชิงกลไก ไฟและเครื่องจักรยังเคลื่อนไหวได้ตามการตั้งค่า ไม่ให้พิมพ์พร้อมหลบและไม่ทำให้พื้นเสียหายซ่อนอยู่ใต้ editor

ให้โค้ดซ่อมหน้าควบคุมจำลอง แล้วผลซ่อมในเรื่องเปลี่ยนอุปกรณ์สนามจริง เช่น แยกเป้าหมาย เปิดสะพาน หรือปลดเกราะ ไม่สอนว่า CSS เป็นเกราะเครือข่ายจริง

1. **ล่าตัวจริง:** NULL สร้างภาพแทรกบนจอและโดรนเตือนแนวยิง ผู้เล่นอ่านสัญญาณเตือน เคลื่อนคินไปคอนโซล แล้วกู้แหล่งภาพ/ลิงก์ต้นฉบับเพื่อระบุเป้าจริง การตอบถูกต้องทำให้ข้อมูลใหม่ใช้ได้ในสนาม ไม่ใช่เพียงลด HP
2. **ยึดสนามคืน:** บอสเปลี่ยนแนวโจมตีและทางเดิน ผู้เล่นเลือกซ่อมอุปกรณ์ช่วย เช่น โล่คุ้มกันหรือสะพานเข้าถึงตัวส่ง โดยมีป้ายอธิบายผลก่อนเลือก งาน CSS เป็นการกู้หน้าควบคุมที่เสีย จุดโจมตี NULL เปิดหลังส่งคำสั่งสำเร็จ
3. **BLACKBOX OVERDRIVE:** NULL ต่อเข้ากับแกนกลาง เผยรูปทรงใหม่ที่มีตัวตนและท่าทางจริง ท่าที่เรียนรู้จากสองช่วงแรกกลับมาในลำดับใหม่ ทุกครั้งที่ยึดเสาส่งได้ NULL เสียระบบหนึ่งอย่าง ผู้เล่นนำ HTML/CSS มาประกอบหน้าควบคุมสุดท้าย ก่อนคินสวนกลับและถอด BLACKBOX

จังหวะที่ควรจำ: บอสแทรกจอทั่วห้องครั้งแรก, เกราะแตกแล้วพื้นที่เปิดเพิ่ม, คินสวนกลับหลังผู้เล่นเลือกจังหวะ, การคืนไฟเมืองหลังคำสั่งสุดท้าย เอฟเฟกต์มีเสียง impact/รีเลย์/ประตู/สัญญาณ ไม่เพิ่มเสียงพากย์โดยอัตโนมัติ

## การแพ้และความยุติธรรมที่เสนอ

ท่าบอสมีสัญญาณเตือนด้วยรูปร่างและเสียง ไม่ใช้สีอย่างเดียว แพ้เริ่มเฉพาะช่วงปัจจุบัน ร่างโค้ดและหลักฐานไม่หาย ให้ลองใหม่ได้และมีทางเลือกช่วยช่วงแอ็กชัน โดยยังต้องทำโจทย์เอง การใช้ตัวช่วยไม่ลดคะแนนเกม ไม่มีโบนัสบังคับจากความเร็วในการอ่านหรือพิมพ์

ปุ่มมี hover/focus/pressed ฉากมีแสงหรี่ พัดลม จาน/แกนหมุน และการเปลี่ยนสภาพที่สัมพันธ์กับสนาม Reduced motion ลดการสั่น ภาพกระตุกและการเคลื่อนกล้อง แต่ยังเห็นแนวโจมตีและสถานะชัด ไม่มี glitch ทับโค้ดหรือข้อความ

## ข้อตกลงจากผู้ใช้ — 2 พฤศจิกายน 2569

- ผู้เล่นเดินและหลบด้วย WASD แล้วกด E เข้า Hack; อันตรายหยุดระหว่างอ่านและเขียนโค้ด
- จังหวะต่อสู้ประมาณ 6–8 นาที ไม่รวมเวลาคิดและพิมพ์โค้ด เป็นเป้าหมายสำหรับทดลองเล่น
- NULL เริ่มเป็นมนุษย์ในห้อง ก่อนสร้างอวตารดิจิทัลยักษ์จากแกน BLACKBOX ช่วงท้าย ยังไม่ยืนยันว่าเป็นคู่หูคิน
- ผู้ใช้เลือกให้เดินหลบแนวโจมตี มีปุ่มพุ่งหลบและโหมดช่วย
- ทางโล่และทางสะพานต้องเป็นทางเลือกที่ผ่านได้ทั้งคู่ และเปลี่ยนวิธีต่อสู้จริง

## ขยายการเล่นหลังคำตอบรอบสอง — ข้อเสนอรอตกลง

การควบคุมที่เสนอ: WASD เดิน, Space พุ่งตามทิศที่กด/ทิศที่หัน, E ใช้คอนโซลหรือสวนกลับเมื่อมี prompt ใช้พุ่งเป็นครั้งพร้อมแถบคืนความพร้อม ไม่กดรัวเพื่อคงสถานะอมตะ ปุ่มพุ่งไม่ทำงานใน editor และไม่ใช้ Space แย่งการกดปุ่ม UI

ท่าร่างมนุษย์: เลเซอร์กวาดแนวที่ทำเครื่องหมายก่อนยิง, โดรนล็อกตำแหน่งแล้วพุ่งให้ผู้เล่นหลบออก, ช่วงจอปลอมซึ่งหยุดได้ด้วยการกู้ต้นฉบับ หลังโจมตีหนัก NULL มีช่วงพักเปิดให้เข้าถึงคอนโซล/สวนกลับ ไม่มีการโจมตีที่ออกทันทีโดยไม่บอกล่วงหน้า

| ทางเลือกช่วงกลาง | สนามเปลี่ยน | วิธีเล่นหลังซ่อม |
| --- | --- | --- |
| เครื่องสร้างโล่ | เสาคุ้มกันสองฝั่งกางแนวกำบังเป็นจังหวะ | ย้ายกำบังระหว่างโดรนเข้าประชิด แล้วรอจังหวะสวนจากระยะปลอดภัย |
| สะพานข้อมูล | เปิดทางยกระดับเข้าถึงเสาส่งด้านข้าง | ใช้ทางใหม่อ้อมคลื่นบนพื้น ระวังแนวเลเซอร์ที่บอกล่วงหน้า แล้วสวนที่เสาส่ง |

สองทางต้องมีงานเขียนและความเข้าใจเทียบเคียงกัน จำนวนโจทย์แกนหลักเท่ากัน ไม่เพิ่มโดรนซ้ำเพื่อยืดเวลาทางโล่ ผลทางเลือกแสดงในเฟสยักษ์ด้วย: โล่ช่วยบังท่ากวาดบางแนว ส่วนสะพานเป็นเส้นทางเข้าถึงเสาส่ง ไม่ล็อกผู้เล่นจากการชนะเพราะเลือกทางใดทางหนึ่ง

ท่าร่างยักษ์: ฝ่ามือลงบนพื้นหลังเกิดพื้นที่เตือน, คลื่นข้อมูลเว้นช่องให้หลบ, ลำแสงกวาดที่ใช้กำบังหรือเส้นทางซ่อมไว้รับมือ ให้เห็นแกนเสาส่งดับลงเมื่อถูกยึดคืน เพดาน/เมืองด้านหลังคืนไฟเป็นส่วน ๆ ความคืบหน้าอ่านได้จากฉากร่วมกับ HUD

โหมดช่วยที่เสนอ: เพิ่มเวลาสัญญาณเตือน ลดความเสียหาย และแสดงทิศทางปลอดภัย ให้ผู้เล่นยังควบคุมเอง เปิดระหว่างลองใหม่ได้ ไม่ทำ Puzzle/โค้ดแทน และไม่ลดคะแนนเกม รายละเอียดนี้ยังรอผู้ใช้เลือก

โจทย์ที่เสนอ: จุด Hack หลักสามครั้ง ครั้งละหนึ่งโจทย์สั้นต่อเฟส มีโครงให้แก้ประมาณ 4–8 บรรทัดตามงาน ไม่จับเวลาและไม่จำกัดบรรทัดคำตอบทางเลือกที่ถูกต้อง การตรวจ/คำใบ้ไม่ถือเป็นการส่งคำสั่งจนกดส่งจริง รายละเอียดนี้ยังรอผู้ใช้เลือก

## คำถามรอบถัดไป

1. โหมดช่วยเพิ่มเวลาเตือน/ลดความเสียหายโดยผู้เล่นหลบเอง หรือให้ช่วยพุ่งหลบอัตโนมัติด้วย?
2. จุด Hack หลักสามครั้งต่อไฟต์ หรือแบ่งเป็นหกครั้งที่สั้นกว่า? แนะนำสามครั้งเพื่อคงช่วงต่อสู้ต่อเนื่อง โดยการเลือกทางโล่/สะพานไม่เพิ่มจำนวนโจทย์บังคับ

## คำถามรอบแรกที่ตกลงแล้ว

1. การควบคุม: เดิน/หลบด้วย WASD และใช้ E เข้า hack แบบหยุดอันตราย หรือสั่งคินย้ายตำแหน่งและตอบโต้เป็นเทิร์น? แนะนำแบบผสมเดิน+hack แต่ต้องตกลงการช่วยช่วงแอ็กชันก่อนกำหนดความยาก
2. ความยาว: บอสประมาณ 6–8 นาทีหรือ 12–15 นาที โดยเป็นเพียงเป้าหมายก่อนทดลองเล่นและไม่นับเวลาที่ผู้เล่นอ่าน/แก้โค้ดนานกว่านั้น? แนะนำ 6–8 นาที ให้สามช่วงเปลี่ยนพฤติกรรมชัด ไม่มีการวนโจทย์เดิมเพื่อยืด HP
3. รูปแบบบอสสุดท้าย: NULL เป็นมนุษย์ต่ออุปกรณ์/โดรน หรือมีร่างอวตารดิจิทัลขนาดใหญ่ร่วมกับตัวจริงในห้อง? แนะนำเริ่มเห็นมนุษย์ก่อน แล้วเปลี่ยนเป็นอวตารที่เชื่อมกับแกน BLACKBOX ในช่วงท้าย ไม่ใช่ยืนยันตัวตนคู่หู

## ยังไม่ตัดสิน

ค่าความเสียหายและเวลาคืนพุ่งต้องจูนจากต้นแบบ; รูปแบบโหมดช่วย จำนวนจุด Hack โจทย์แต่ละช่วงและวิธีตรวจยังรอตกลง บทจบ/ชะตา NULL/ตัวจริงคู่หู และเพลงหรือสิทธิ์ Asset เพิ่มเติมเป็นงานบทที่ยังไม่อนุมัติ ไม่เพิ่มระบบต่อสู้ทั่วไปหรือแยกเกมอีกชุดในรอบสนทนานี้
