6. ภารกิจที่ 8 — Boss Fight: NULL

ใช้คินและ NULL ขนาดปกติในฉาก 2D
มีแท่น BLACKBOX อยู่กลางห้องและจอระบบอยู่ด้านหลัง
การโจมตีเกิดจากการแก้โจทย์สำเร็จ ไม่ใช่กดโจมตีรัว

แบ่งเป็นสามช่วง:

ช่วง A — เปิดโปงหน้าปลอม
NULL ทำหน้าหลักฐานให้โครงสร้างผิด
ผู้เล่นแก้ HTML และลิงก์ให้กลับมาอ่านต้นฉบับได้
คำตอบถูก: คินส่งสัญญาณโจมตี เกราะชั้นแรกแตก

ช่วง B — คืนหน้าจอ
NULL แทรก CSS ทำให้ข้อความอ่านไม่ได้และกรอบล้น
ผู้เล่นตรวจ selector สี และ box model
คำตอบถูก: จอด้านหลังคืนภาพ เกราะชั้นสองดับ

ช่วง C — ยืนยันต้นฉบับ
ผู้เล่นประกอบหน้าสรุป HTML/CSS จากโครงที่ให้
ต้องมีโครงสร้างเหมาะสม ลิงก์ต้นฉบับ ภาพพร้อม alt
และการจัดวางที่อ่านได้
คำตอบถูก: ยกเลิกคำสั่งปลอมและปลด BLACKBOX จากแท่น

แต่ละช่วงใช้เฉพาะทักษะที่สอนแล้ว
ไม่จับเวลาอ่านหรือพิมพ์

ผู้เล่นมีโล่สามช่อง
ตอบผิดให้คำอธิบายและเสียหนึ่งช่อง
โล่หมดเริ่มใหม่เฉพาะช่วงปัจจุบัน
ไม่ลบหลักฐานหรือคะแนนที่ทำสำเร็จแล้ว

ทำ animation ชัดเจน:
NULL ส่งสัญญาณแทรก คินตอบโต้ เกราะแตก
แสงจอคืนสภาพ และแท่น BLACKBOX ปลดล็อก
ไม่ใช้การสั่นหรือเลื่อนภาพทั้งใบแทนท่าทางทั้งหมด
