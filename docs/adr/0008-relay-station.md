# ADR 0008 — Playable relay chapter and recovered case evidence

Status: accepted, 2 November 2026. Local desktop iteration, no publication.

## Decision

The active chapter is explicit and separate from `street`/`device`. Field adapters preserve the Phaser lifecycle; Circuit chapter adapters share the existing 7+1 stage shell and coordinate-based camera module. A separate relay module owns puzzles, HTML validation, local observations and story flags. CodeMirror remains the reusable editor interface. This gives two real adapters and improves locality without a generic mission framework.

The repair module handles either chapter session but cannot award progress by checking, selecting or preview navigation. Each station Puzzle exposes a distinct interaction matched to its HTML skill. Local drafts survive modal revisits within their owner/reset scope, not closing the browser.

Case v2 adds recover-relay; old read-relay/read-control mean historical intel only. Version1 cases normalize to version2 at client/cache/API reads. Existing historical flags survive, but control requires recovered relay evidence. Old control locations without that evidence normalize to relay. Revision/generation safeguards and the PostgreSQL JSON column remain unchanged; no schema migration or real database mutation was performed for this iteration.

Only case milestones sync. Cross-device evidence visibility derives from case progress; it never fabricates local learning completions. Detailed relay saves have their own owner/reset-generation key. Reset cannot revive prior-generation evidence.

## Preview seam

Arun's image-only sanitizer removed all href attributes, so it could not teach links. Relay has an explicit fixture adapter: sanitized Blob documents and same-document fragments only. The iframe has allow-same-origin so the host can own fixture navigation, but never allow-scripts, forms, popups or top navigation. Unknown/external protocols and event attributes are removed; original-record content is unavailable before stage8. Blob URLs and listeners are released on session disposal.

## Presentation

Keep original Kin, music transport and story canon. Station art uses the workshop as a visual reference with source-aligned layers. Practical lamps, separate dish, fan and data signals animate without moving the room plate. DOM owns Thai text; 2D/3D world renderers remain exclusive. Muting/reduced motion are existing player preferences, not a new account setting.

## Validation

Model/API tests exercise access gates, legacy migration, independent owner/reset scopes and actual final evidence. Desktop browser flows exercise seven distinct puzzles, editor semantics and the full physical investigation. Existing Arun chapter remains a regression target. No mobile or online playtest is included.
